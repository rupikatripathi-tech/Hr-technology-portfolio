# 📊 Recruitment Analytics Dashboard

## Project Overview

A Power BI dashboard designed to analyze recruitment data and provide insights into the hiring process.

## Business Problem

HR teams need visibility into recruitment performance, including:

- Number of applications
- Candidates moving through the recruitment funnel
- Interview conversion
- Offers made
- Offers accepted
- Time-to-hire
- Recruitment source effectiveness

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
